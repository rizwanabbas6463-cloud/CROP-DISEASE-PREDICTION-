# 🌱 Crop Disease Prediction Using Machine Learning

##  Project Overview
This project focuses on **Crop Disease Prediction using Machine Learning** techniques. The goal is to analyze crop-related symptoms and identify disease patterns through data analysis and predictive modeling.

The project includes:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Class distribution visualization
- Feature correlation analysis
- Machine learning-based disease prediction

##  Visualizations

### Target Class Distribution
The dataset contains healthy and diseased crop samples with balanced class distribution.

### Feature Correlation Heatmap
A correlation heatmap is used to identify relationships between symptoms/features and disease prediction.
